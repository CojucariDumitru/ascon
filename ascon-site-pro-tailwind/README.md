# ASCON GROUP INC — Website (Pro Edition)

## Run locally
```bash
npm i
npm run dev
```

## Deploy on Vercel
- Import this repo.
- Add SMTP env vars (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, optional SMTP_FROM).
- The contact form and Quote Wizard post to `/api/contact` (serverless).

## Build
```bash
npm run build
npm run preview
```
